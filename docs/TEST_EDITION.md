# CrossDesk Test

这是独立测试版。正式版的配对、证书、设置和外观不会导入测试版，也不会被清理工具删除。

## rc23：修复 Mac 已授权却被阻止共享

- 已获得输入监控和输入控制权限时，即使独立的辅助功能检查返回 false，也允许用户启用共享；不再要求三个原始检查全部为 true。辅助功能本身已覆盖两种能力时，也无需重复申请输入监控。
- 界面、启用预检、设备就绪状态和实际输入路径使用一致的权限规则。原始结果仍保留在诊断中，不伪造授权，不自动启用共享。
- 本轮只更新 Mac。Windows rc20 / rc22 可以继续使用，协议不变；测试版配对、配置和本机鼠标速度保留。不要运行卸载工具来升级。
- Mac：在旧版的设置中选择“退出并停止共享”，解压本包，打开其中的 `CrossDesk Test.app`。无需编译。
- 仍使用临时签名且未公证。新包可能需要重新授权：若两项显示可用，直接点击“启用共享”；若系统开关已开但后台仍未取得，请完整退出后，按下方步骤仅清除测试版旧授权，再打开本包申请。不要反复开关，也不要清除所有应用权限。

仅在新包确实无法取得权限时，在终端执行：

```sh
/usr/bin/tccutil reset Accessibility dev.crossdesk.desktop.test
/usr/bin/tccutil reset ListenEvent dev.crossdesk.desktop.test
/usr/bin/tccutil reset PostEvent dev.crossdesk.desktop.test
```

这些命令不删除配对或配置。然后打开本包，由应用内按钮跳转系统设置并授权；按系统要求完整退出、重新打开一次。稳定签名升级、实体 Mac 键鼠控制仍待验收，构建成功不等于实机通过。

## rc22：Mac 权限引导与离线电脑布局保存

- Mac 未开启权限时，工作区显示“设置权限”；点击“启用共享”进入权限引导。分别显示辅助功能、输入监控的实际后台检查结果。
- 点击“打开辅助功能”或“打开输入监控”，由实际负责键鼠的后台向 macOS 申请，再打开对应系统设置页。不会在启动或轮询时弹出系统请求，不会自动授予权限。
- 返回后自动重新检测，也可点击“重新检测”。两项通过后再点击“启用共享”。系统若要求重新打开，请先在软件设置中退出再启动。
- 若系统仍不列出应用，可在对应权限页点击“＋”选择当前 CrossDesk Test.app；若系统单独列出 crossdesk-test-daemon，它是包内后台。临时签名升级后的权限识别仍需实机验证。
- 修复另一台电脑未上线时，调整当前两台方向或鼠标速度会报“invalid edge interval or missing monitor”的问题。原离线电脑路线保留，新写入的无效屏幕/范围仍拒绝。
- Windows 与 Mac 建议都升级 rc22，保留测试配对和本机速度；与 rc18–rc20 协议兼容。升级不运行卸载清理工具。

## rc20：第三台电脑连接与布局同步

- 修复已保存 Windows 两机布局后，新电脑加入时自动路线占用同一边缘，导致 `overlapping edge links` 并断开 TLS 的问题。保留已有布局，为新电脑选择空闲边缘，将采用的位置保存并同步到对端。
- 修复重启时部分电脑的屏幕信息尚未到达，就把其已保存路线判成“缺失屏幕”的问题。离线电脑的位置保留，当前连接只使用已确认在线的屏幕。
- Windows / Mac 建议都更新到 rc20，继续使用原测试版配对，不必重新配对或清理配置。协议与 rc18 / rc19 兼容，rc17 不兼容。
- 本轮没有放宽路线重叠、设备身份或输入安全校验。真实跨平台控制仍需用户实机测试。

## rc19 已有功能：输入暂停诊断

- 修复在本机使用不支持转发的特殊输入时，误暂停整个共享的问题。远端不支持的输入仍先释放控制，不能宣称所有特殊按键已经兼容。
- 区分调度停顿、切换等待、输入队列、特殊输入、本机释放失败等暂停原因。右上角“启用共享”得到后台成功确认后，撤下已解决的错误提示。
- 自动保留最近 16 次会话停止的时间、固定原因类别及可用的等待毫秒数。记录在测试数据目录的 `safety-events.json`，设置中导出 `diagnostics.json` 会包含这些记录。恢复共享和重启不会清除；不记录按键、输入文字、设备名称、IP 或证书。
- Ctrl + Win 长按不被核心状态机当作超时。微信在本机响应该快捷键的具体原因仍待实机验证，rc19 不宣称已修复第三方全局快捷键兼容问题。
- rc19 未更改协议，与 rc18 兼容；rc17 及更早版本不兼容。rc20 的 Mac 包也包含这些诊断改进。
- 暂停后先松开按键，再点击右上角“启用共享”。若提示输入清理未确认，需在设置选择“退出并停止共享”后重新打开。无需撤销信任或重新配对。

## rc18 已有功能

- 工作区“电脑方向”下面的“鼠标移动”只在本机保存，不同步到其他电脑。滑条左减右加，每次 0.05×；仅改变本机鼠标跨电脑后的移动倍率，不改变硬件 DPI。
- 设置 → 输入与快捷键 → 跨机切换按键，可选“自定义按键”，直接按下单键或组合键，全部松开后自动保存。支持常规键盘键（含字母、数字、F1–F12、方向键、Ctrl / Shift / Alt / Win 或 Command）；也可选“无需按键”。组合键最多 6 个，不能包含当前紧急释放快捷键。系统保留组合及 Fn / 媒体键可能无法录入。
- 每台电脑均可用自己的鼠标发起跨机控制。被控制时移动本机鼠标，立即接回本机；此前控制结束，双方连接保留，之后可重新跨边缘。

- 两边至少为 rc18。rc18 同步协议有调整，不能与 rc17 或更早测试版混用；旧版只显示未连接，原因可在诊断中查看。退出旧测试程序后解压新包即可，原测试版配对和各机现有速度保留，无需重新配对或运行卸载清理工具。
- 左键拖动电脑屏幕，松开后自动应用、保存并同步。右键移动画布，Ctrl + 滚轮缩放。
- 鼠标速度、切换按键、外观等修改后自动保存，不再点击“保存设置”。连续调整会合并，保存中仍可编辑；失败时保留修改并提供重试。
- 鼠标速度在本机输入线程即时应用；主题切换不重新建立连接。改变切换规则时结束旧控制，再应用新规则。端口、网络范围和租约改变时重新连接。
- 布局、切换按键和其余共享偏好会同步；鼠标速度、设备地址、监听端口、权限及本机暂停状态保持独立。此前被同步覆盖的历史速度无法自动推断，请在各机重新设定一次，之后分别保留。

## 打开

- Windows：解压整个文件夹，打开 `crossdesk-test-desktop.exe`。
- Mac：选择对应芯片的压缩包，解压整个文件夹，打开 `CrossDesk Test.app`。不需要安装 Node、Rust 或编译源码。
- 两台都打开 **CrossDesk Test**；第一次使用测试版时配对一次。测试版只与测试版连接。
- 进行键鼠测试前先暂停正式版共享，避免同时运行两套捕获。不要删除或重新配对正式版。
- Mac 第一次可能需要系统安全确认，以及辅助功能/输入监控权限。只授予 CrossDesk Test；不要关闭系统安全检查。当前包使用临时签名，未公证。

## 更新测试包

构建并验证新测试包后，打包脚本自动清理同平台、同芯片的旧测试包。其他平台保留最新可用包；正在运行的旧包和含额外用户文件的目录会跳过。

升级只替换程序文件，保留测试版设置和配对。不要为了升级运行下面的卸载清理工具。

## 删除

1. 在 CrossDesk Test 的设置或菜单栏/托盘中选择“退出并停止共享”。关闭窗口不等于退出。
2. 双击解压文件夹中的 `Cleanup-CrossDesk-Test.command`（Mac）或 `Cleanup-CrossDesk-Test.cmd`（Windows）。看到完成后继续下一步；若提示仍在运行，先退出测试版再重试。
3. 删除整个解压文件夹和下载的 zip。

清理会删除测试版的配对、私钥、设置、日志、诊断文件及界面缓存。Mac 会同时清理测试版专用钥匙串，并尝试移除测试版权限记录；如系统提示不能自动移除，可在“系统设置 → 隐私与安全性 → 辅助功能 / 输入监控”中只移除 **CrossDesk Test**。不会删除正式版权限或其他应用数据。不安装开机启动项。

你主动另存到其他位置的导出文件、浏览器下载记录和系统自身日志不属于应用数据，清理工具不会搜索或删除它们。
